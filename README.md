## Lista de comandos
| Comandos Git | Descripción |
| :--- | :--- |
| **git init** | *para crear un repositorio de Git nuevo y vacío o para reinicializar uno ya existente.* |
| **git status** | *sirve para ver el estado actual de tu repositorio de Git en el directorio de trabajo.* |
| **git branch** | *sirve principalmente para crear, listar y eliminar ramas en tu repositorio de Git.* |
| **git commit** | *sirve para guardar de forma permanente los cambios preparados en el historial de tu repositorio.* |
| **git add .** | *sirve para preparar absolutamente todos los archivos nuevos, modificados o eliminados del directorio actual para el siguiente guardado (commit).* |
